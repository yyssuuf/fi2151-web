Tentang halaman ini

Halaman ini dibuat untuk tugas hands-on pembuatan situs statis dengan GitHub Pages. Empat latihan diagram Mermaid yang dikerjakan sebelumnya dirangkum di bawah, masing-masing tertaut ke issue repositorinya.

Latihan diagram

  • #1 Flowchart Alur menghitung 1 + 2 + … + n dengan on-page connector.
  • #2 Mind map Peta materi PGDA: pemodelan, generator data, analisis, dan alat.
  • #3 Concept map Hubungan data, informasi, pengetahuan, dan keputusan.
  • #4 Equation Persamaan kuadrat: rumus, diagram alir, kode, dan hasil.

Cara halaman ini dibuat

  1. Membuat repositori publik Repositori fi2151-web dengan lisensi MIT.
  2. Menambahkan halaman dan tampilan docs/index.html dan docs/style.css.
  3. Mengaktifkan GitHub Pages Settings → Pages → branch main, folder /docs.

GitHub Pages menyajikan berkas itu apa adanya dari branch main — tanpa kompilasi atau alat build.
